# Interface web d’activités

Navigation dynamique, formulaire d’inscription et affichage d’une carte intégrée.

## Technologies

HTML, CSS, JavaScript.

## Installation et utilisation

Ouvrir `document.html` dans un navigateur. La carte intégrée requiert une connexion Internet.
